バックアップ管理

Supabase のデータを暗号化して、Google ドライブのフォルダへ保存・復元します。

2. 設定

保存先フォルダ

Google ドライブ for desktop の同期フォルダ(マイドライブ内)を選んでください。中に「SupabaseBackup」フォルダを作ります。

このブラウザはフォルダへの直接保存に対応していません。バックアップは通常のダウンロードで保存されます。保存後に、手動でドライブへ移してください(PC の Chrome / Edge を推奨)。

暗号化の鍵

作成すると「秘密鍵ファイル」が保存されます。このファイルとパスワードの両方を失うと、バックアップは二度と復元できません。別の場所にも控えを保管してください。

3. バックアップ

全アプリのデータを取得し、アプリごとに暗号化して保存します。クラウドのデータは変更しません。

    4. 履歴

    各アプリ最新10世代を残し、古いものは削除せず「_old」フォルダへ移します。

    5. 復元

    復元前に、現在のクラウドの内容を自動で保存します。バックアップに無い行は削除しません。
